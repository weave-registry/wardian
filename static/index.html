          Make apps with Claude
          
      
          
      
          
        Claude runs on
        
        
      
          
      
          
      
          
        
        
        
      
          
      
          
        
      
          
      
          Get a key at console.anthropic.com → API keys. Wardian tests the key, then keeps it on this server only; it never comes back to the browser. Each app costs some API use, billed to that key. Apps with AI features (claude:sample) use the same key, after you allow them. Some keys belong to no one workspace; the API then asks for a workspace ID, which the Console shows under Settings → Workspaces.
          
      
          
      
          
        
          
          
          
          
        
          
        
          
          
          
          
        
          
        
          
          
        
          
        
          
          
          
          
        
          
        
          
          
          
        
          
        
          Claude through your AWS account, billed by AWS, in the region you choose. The model must be enabled for the account in that region (Bedrock console → Model access). Wardian tests the settings with one tiny request before it saves them, keeps them on this server only, and never sends a key or secret back to the browser. Leave a key field empty to keep the saved one. With an AWS profile from ~/.aws/config, Wardian keeps only the profile's name and region, and gets short-lived keys from AWS CLI v2 (or the profile itself) when it needs them; after an SSO sign-in expires, run aws sso login --profile with the profile's name.
