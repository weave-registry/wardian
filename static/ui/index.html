Wardian

Components

Ready-made parts for page apps and suites. Like shadcn, you copy them into your package and they become your code: the package stays complete on its own, and you may change any file. One theme file sets the colours, corners and spacing for all of them.

wardian add button tabs toast apps/my-suite copies the files into apps/my-suite/ui/. For a suite it also lists them in suite.json; for a page app it prints the lines to add to your page. wardian add --list shows every component.
