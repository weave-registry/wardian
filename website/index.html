A FEW GOOD QUESTIONS

Good to know.

Is Wardian a hosted app platform?

No. Wardian is a Rust application you run on a computer you control. This website introduces the project, and runs eleven of the example apps in your browser to show them. Your own apps run through your own Wardian server.

Do I need AI to use it?

No. You can build apps yourself using the module, page, and suite templates. AI-assisted creation is optional and requires configuring your own Anthropic or Amazon Bedrock access.

Can apps access my data or other services?

Access depends on the package type and declared capabilities. Suite components are sandboxed, communicate through the kernel, and need permission for sensitive services such as Splunk and cross-package channels. Read the security model for the exact boundaries.

Is it open source?

Yes. Wardian is MIT licensed. You can inspect the source, build it yourself, and contribute on GitHub.
